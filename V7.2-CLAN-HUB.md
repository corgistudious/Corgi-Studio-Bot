# Corgi Studio V7.2 — Clan Hub
- `/clan` and `/clan-hub` open the direct-action Clan Hub.
- Direct button actions: Members, Missions, Shop, Treasury, Applications, Events, Audit, Refresh, Deposit CXu.
- Direct slash/prefix parity commands added for Clan Hub views and CXu treasury/shop actions.
- Existing management subcommands preserved under `/clan-manage`.
- Clan Shop, mission currency rewards and treasury now use the existing global CXu wallet. No new Clan currency is created.
- Legacy Clan member currency fields remain in MongoDB for backward-safe schema compatibility but are no longer used for purchases/rewards.
- No player balance, Clan membership, rank, contribution or progression reset.
