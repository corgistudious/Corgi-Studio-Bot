# Creature Hunt V2
Adds the complete Creature/Pet game layer without deleting existing captured pets: 8 elements, Hub, Collection, 3-slot Team, Companion, Hunt Zones, PvP, HP/ATK/DEF/SPD scaling, EXP/Level Up, Skill levels, Pet Essence, Favorite/Lock, PvP victory/defeat presentation and Dex milestones.

New commands: `/petmanage`, `/dex`. Existing `/pet`, `/hunt`, `/collection`, `/team`, `/battle` remain compatible.
Assets live in `assets/creature-hunt/ui-v2/` and all 31 supplied/approved UI assets are retained.
