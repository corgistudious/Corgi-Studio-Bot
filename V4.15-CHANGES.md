# Corgi-Bot V4.15.0 — Global Progression & Gaming Profile

## Global Level & EXP
- One global Level/EXP profile per Discord user across every server.
- Default XP: 15–25 per qualified message, 60 second cooldown.
- Maximum Level: 100,000.
- Default non-linear curve: `250 × (1 + Level / 10) ^ 1.35` EXP for the next level.
- Developer Control can tune XP min/max, cooldown, max level, curve base/divisor/power.
- Server `/setup` can enable/disable Level & EXP collection for that guild.

## Weekly Global Ranking
- `/ranking` and `?ranking` support Weekly and Global EXP leaderboards.
- Weekly season uses Monday 00:00 UTC → next Monday 00:00 UTC and displays a countdown.
- Rewards are NOT auto-sent on a timer.
- Developer presses **🎁 Approve Reward** whenever desired; the current Top 100 is snapshotted and paid automatically.
- One approval batch per weekly season prevents duplicate payout.

## Weekly titles — 7 days from approval
- #1: **Thần Vương Vô Địch**
- #2: **Á Vương Vô Địch**
- #3: **Quý Vương Vô Địch**
- #4–10: **Chiến Thần Top 10**
- #11–100: **Đại Gia Mới Nổi**
- Achievement history and best weekly rank remain permanently on the profile.

## Default weekly 🌟Cstar rewards
- #1: 100,000
- #2: 60,000
- #3: 40,000
- #4–10: 20,000 each
- #11–100: 10,000 each
- Developer can change every bracket before Approve Reward.

## Professional Gaming Profile
- New `/profile [user]` and `?profile [@user]`.
- Shows Level, EXP progress bar, Global Rank, Weekly Rank, Weekly EXP, 🌟Cstar, active title, VIP status, activity, reward history, best weekly rank.
- Expired weekly titles are automatically removed from active display while achievement history is preserved.

## VIP Profile
Tiers:
- VIP
- VIP+
- VVIP
- SVIP
- SSVIP
- SSSVIP

Activation is intentionally restricted to:
1. VIP Profile CD Key; or
2. Expensive 🌟Cstar purchase.

Default 🌟Cstar price / 30 days:
- VIP: 250,000
- VIP+: 500,000
- VVIP: 1,000,000
- SVIP: 2,500,000
- SSVIP: 5,000,000
- SSSVIP: 10,000,000

Developer Control can edit VIP prices and create VIP CD Keys with 7d / 14d / 21d / 30d / 90d / 1y durations.
