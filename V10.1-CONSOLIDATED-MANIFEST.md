# Corgi-Bot V10.1 Consolidated Upgrade

Built from the supplied production source `Corgi-Studio-CURRENT(2).zip`.

## Changes included in this package

### Pet Hunt performance
- ACK-first component handling before database / asset work.
- Immediate Hunt searching state so the Discord interaction visibly responds before encounter work completes.
- Dynamic catalog overlay is cached in memory and invalidated after Developer catalog changes.

### `/dev` → Pet Hunt catalog manager
- Add Pet with uploaded PNG/WebP/JPG asset.
- Replace an existing Pet asset.
- Enable / disable a Pet from Hunt without deleting player ownership.
- Delete a dynamic Pet and its managed asset.
- Asset replacement writes the new file before removing the previous managed file.
- Existing player-owned Pet records are not deleted when a catalog Pet is disabled/deleted.

### Fishing stability
- Fishing component interactions now `deferUpdate()` before DB/gameplay work.
- Prevents the known `InteractionAlreadyReplied` path caused by replying after the global interaction ACK.

## Existing production systems preserved
The package is based on the current production tree rather than the discarded V1 demo. Existing Profile, progression, missions, CXu, Startup, Clan, Marketplace/Frontier, Global Mail, website roles, moderation, Giveaway/Contest infrastructure, Pet Hunt/Fishing systems and VI/EN files are retained.

## Important scope note
This manifest only claims changes actually present in this build. Features not listed under "Changes included" are preserved from production, not represented as newly rewritten.

## Safety
- `.env` is not included.
- No database migration is run automatically.
- Dynamic Pet catalog uses additive configuration and does not rewrite player ownership documents.
