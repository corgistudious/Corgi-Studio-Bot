# Corgi-Bot V7.0 — Corgi Frontier

- Removed weekly ranking race/reward controls. `/ranking` is permanent all-time EXP only.
- Removed monthly Game Hub tournaments and scheduler.
- Removed Seasonal Events gameplay, notifier and developer controls.
- Replaced Game Hub entry with **Corgi Frontier — Thế Giới Khai Phá**.
- `/frontier` is the flagship game; `/games` now opens Frontier for backward compatibility.
- Direct Action UX: gameplay buttons execute immediately; no Immortal-style nested gameplay tabs.
- Persistent Frontier profile: Explorer Rank/XP, energy, supplies, regions, discoveries, creatures, artifacts, resources, base progression and expedition history.
- Existing player/economy/fishing/profile data is preserved. Retired collections are not dropped automatically.
- Developer Control menu is streamlined by removing Weekly Ranking, Tournament and Seasonal Event tools.
