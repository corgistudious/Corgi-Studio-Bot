# Corgi-Bot V4.18.0 — Developer Titles & Global Mail

## 🏷️ Developer Custom Profile Titles
- New `/dev → Custom Profile Titles` configuration panel.
- Developer can create reusable custom title definitions with:
  - unique key
  - display name
  - emoji/icon
  - description
  - permanent or timed duration
- Developer can grant, revoke, enable, and disable titles from the panel.
- Granting a custom title makes it the member's active custom profile title.
- Custom titles are stored separately from Weekly Ranking title history so existing ranking achievements are preserved.
- `/profile` displays the active custom title first; when no custom title is active, the existing Weekly title remains the fallback.

## 📬 Developer Global Mail + 🌟Cstar
- New `/dev → Global Mail` configuration panel.
- Developer can compose a draft with title, message, optional HTTPS image, optional 🌟Cstar attachment, and optional claim expiry.
- Panel includes Preview, Broadcast All Servers, and Discard Draft.
- Broadcast delivery chooses a writable text/announcement channel in each guild, preferring system/log/welcome channels when available.
- Delivery summary records Sent / Failed / Skipped per broadcast.
- 🌟Cstar reward uses the GLOBAL wallet.
- Each Discord account can claim a given mail reward only once globally, even when the user belongs to multiple servers.
- Claim protection is atomic at the wallet record using `claimedGlobalMailIds`.
- Claim audit records are stored separately in `GlobalMailClaim`.

## 🔐 Permissions
- All title creation/grant/revoke/toggle controls are Developer-only.
- All Global Mail compose/preview/broadcast/discard controls are Developer-only.
- Normal members only see the broadcast and can use the reward Claim button when a 🌟Cstar attachment exists.

## Compatibility
- Built on the V4.17.0 full source with the V4.17.1 Stats interaction timeout fix and V4.17.2 Stats self-count fix already applied.
- No new npm dependencies.

## Premium Identity Branding
- Bundles official Global and Premium Corgi-Bot logos.
- Active Premium guilds automatically use the Premium guild avatar.
- Free/expired guilds remove the guild avatar and fall back to the global bot logo.
- Existing Premium custom bot name and custom avatar remain supported; custom avatar takes priority over the default Premium logo.
- Uses the guild member profile avatar endpoint; never changes the bot account global avatar.
