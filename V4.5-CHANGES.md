# Corgi-Bot V4.5 — Access + Premium enforcement

This upgrade connects the V4.4 Developer Control switches to real bot behavior.

## Global access control
- Guild blacklist now blocks slash commands, prefix commands, buttons, select menus and modals.
- User blacklist now blocks slash/prefix/component/reaction usage by that account.
- Maintenance mode blocks normal bot usage globally.
- Developer IDs bypass blacklist/maintenance so `/dev` can always be used to recover the bot.
- Autonomous server features (stats refresh, giveaway completion, contest completion, welcome/leave and server logs) pause for blacklisted guilds / maintenance.

## Premium
- AI is now Premium-only at the central command gate.
- Premium-only module activation is rejected from `/setup` when Premium is inactive.
- `/premium status`, `/premium benefits`, `/premium history` are available.
- Premium expiration is time-based and effective immediately for protected commands.
- Premium configuration is retained after expiry.
- Premium server nickname branding is removed when inactive and reapplied after renewal.
- Corgi Studio emoji mode can be toggled from `/setup` while Premium is active.
- Grant, extend, redeem, revoke, expire and branding activity is recorded in MongoDB (`PremiumAudit`).
- Developer Premium page shows recent audit activity.

## CD Keys
- Premium/Cstar key redemption reserves a use atomically and rejects repeat use by the same user in the same guild.
- Failed reward application rolls the reserved use back on a best-effort basis.
- Developer log messages are sent when `DEVELOPER_LOG_CHANNEL_ID` is configured.

## Important Discord limitation
Bot account avatar is global across every guild. V4.5 keeps global avatar mutation protected by `ALLOW_GLOBAL_AVATAR_BRANDING`; per-server nickname remains safe and supported.
