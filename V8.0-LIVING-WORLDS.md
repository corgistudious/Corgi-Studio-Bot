# Corgi-Bot V8.0 — Game Hub & Living Worlds

## Game Hub
- `/games` is a standalone lobby again.
- Current Hub games: Corgi Fishing + Corgi Farm.
- Frontier is independent at `/frontier`.
- Hub routing is registry-friendly for future games.

## Corgi Farm
- Permanent Farm profile with Farm Level/XP/Coins.
- Seeds, timed plots, harvest, Silo/Barn, chickens/feed, processing, orders and land/storage expansion.
- Guided Next Objective + in-panel Guide.
- Independent Farm progression; existing global CXu economy is not mixed into Farm Coins.

## Living Frontier
- Preserves existing Frontier progression while adding survival state: HP, Energy, Hunger, Thirst, inventory/equipment, danger and tutorial state.
- Food/water/tools are functional resources.
- Exploration now includes risk, injuries, discoveries, creatures, rare resources and weather/biome danger.
- Crafting has visible success chance; Workshop/Crafting Mastery improve it; rare-resource tools are significantly harder.
- Camp restores survival state; Travel/Expedition require preparation.
- One-time guided tutorial + Next Objective + Guide + Codex unknowns.

## Migration
Run `npm run migrate:v8` once before restarting V8 production. It backfills only missing Frontier V8 survival fields and initializes Farm indexes; Fishing and existing Frontier progression are preserved.
