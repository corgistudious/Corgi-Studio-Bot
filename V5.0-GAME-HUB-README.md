# Corgi-Bot V5.0 — Direct Action Game Hub

## Included
- `/games` + `?games`: 50-game button/select Game Hub.
- `/game name:<id>` + `?game <id>`: command path into the same shared game state.
- `/tournaments` + `?tournaments`: player Tournament Center.
- `/dev` → Game Tournaments: developer scheduling for future tournaments with automatic registration/start/end.
- Fishing 2.0: cast → hook → tension/reel/hold/release → catch/escape instead of instant result.
- Premium cleanup: STANDARD only; Top.gg review bypass and private Premium-support entitlement removed.
- `/daily`: random 1–10,000 Cstar; active STANDARD Premium doubles the one valid claim (2–20,000).
- VI/EN user-facing Game Hub/Fishing/Tournament surfaces.

## Deploy
```bash
npm install
npm run migrate:v5
npm run migrate:fishing
npm run deploy:commands
pm2 restart corgi-studio-bot --update-env
pm2 logs corgi-studio-bot --lines 80
```

Migration normalizes legacy Premium tier records to STANDARD and removes obsolete support fields without resetting player progression.
