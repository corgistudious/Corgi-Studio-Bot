# Corgi-Bot V5.1 — Global Expansion (work in progress)

## Implemented in this RC
- 12 configured locales: EN, VI, pt-BR, pt-PT, ES, FR, DE, JA, KO, ID, zh-TW, zh-CN.
- Corgi Market virtual Cstar game: fictional assets, buy/sell, portfolio, P/L, Direct Action UI, market movement alerts.
- Server channel settings for Market and Seasonal announcements.
- Seasonal Event engine: Lunar New Year, Christmas, Mid-Autumn, Halloween, Easter, New Year. Valentine is intentionally excluded.
- Seasonal bonus materials can drop from eligible Game Hub actions; Fishing integration is supported by the shared seasonal drop service.
- Crafting uses 1 crafted event item -> 1 Gift Box; boxes grant configured random Cstar rewards.
- Lunar New Year supports direct Red Envelope bonus drops.
- Seasonal lifecycle notifier announces event start/end to the configured server channel.
- Developer seasonal configuration includes enabled state, dates, reward range, and drop multiplier controls.

## Release gate
`npm run audit:i18n` must report zero legacy EN/VI `pick()` surfaces before V5.1 may be labeled Final. The gate intentionally fails while legacy V5 UI remains untranslated for the other locales.
