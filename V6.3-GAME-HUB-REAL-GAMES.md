# Corgi-Bot V6.3 — Curated Game Hub

Game Hub is reduced from 50 generic entries to 15 core games plus CEO Empire (16 total).

## Kept games
Fishing 2.0, Pet Hunt, Pet Arena, Expedition, Dungeon, Mining, Raid Boss, Ghost Hunt, Deep Sea, Alchemy Lab, Zombie Survival, Racing, Cooking Challenge, Café Rush, Farm Life, CEO Empire.

## Design
- Fishing 2.0 remains on its existing dedicated system.
- The other short-session games now have game-specific resources, objectives and action buttons instead of the old shared Careful / Push / Skill template.
- Removed Game Hub IDs are no longer returned by the Game Hub registry, so `/game` rejects them.
- Existing player/economy/fishing data is preserved. Old best-score keys can remain harmlessly in MongoDB and are filtered from the current stats display.

## CEO Empire
Persistent company simulation stored in `CompanyProfile`:
- Register company name and industry through a Discord modal.
- Start with 100% founder ownership and bootstrap cash.
- Recruit by reviewing generated candidate CVs and sending offers.
- Salaries become monthly operating costs.
- Build product, market to acquire customers, generate revenue, raise funding with dilution, close monthly books and track runway/valuation.
- IPO requires operating history, revenue, employees, product maturity and valuation.
- After IPO the company remains playable with stock price and market capitalization.

## Validation
Run `npm run validate` plus `node --check src/modules/gameHub.js` before deployment.
