# Corgi-Bot V4.9.1 — Groq AI + Full Command Guide

- Groq remains the AI provider; `/ai` and `?ai` are FREE.
- No extra AI npm package is required; Node.js 20 `fetch` is used.
- Added a complete `COMMAND-GUIDE.md` covering setup, permissions, slash commands, prefix aliases, Premium, AI, developer controls and operating commands.
- Rebuilt `/help` with categories: all, setup, moderation, economy, games, community, premium, AI, pet and developer.
- Added `?help <category>` support.
- Added a generic prefix permission guard that mirrors each slash command's `default_member_permissions`, preventing prefix moderation commands from bypassing Discord permissions.
- Corrected `.env.example` developer key names to match the source (`DEVELOPER_ID` / `DEVELOPER_USER_IDS`). This does not require changing an already-working `.env`.
- README now accurately documents Groq Chat Completions rather than calling it a Responses API.
