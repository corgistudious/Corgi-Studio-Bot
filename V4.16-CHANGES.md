## V4.16.1 Ticket Transcript + Premium Private Support Add-on
- Ticket close is now two-step: export transcript first, then user/staff confirms close.
- HTML Discord-style transcript includes messages, timestamps, avatars, embeds, attachment links, image previews and video players.
- One transcript copy is attached inside the ticket, one is DM'd to the ticket owner when DMs allow, and one is archived to the ticket-type log channel or server log channel.
- DM failure never blocks ticket closure.
- Star / Plus / Pro / Ultra automatically create or restore a private support channel in the configured Corgi-Bot Support guild when the activating user is present there.
- Standard does not receive a private support channel.
- Expired eligible Premium locks the private support channel and removes the user's entitlement role/access.
