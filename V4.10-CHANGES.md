# Corgi-Bot V4.10 — Pet Coming Soon

- Pet Game is temporarily locked for future development.
- `/pet` and `?pet` now only display a **Coming Soon** notice.
- Removed active Pet subcommands (`profile`, `adopt`, `list`) from the deployed slash command definition.
- Pet no longer consumes Cstar or writes Pet gameplay data.
- `/setup` shows `🐾 Pet Game — Coming Soon` as locked and removes Pet from the toggle menu.
- Existing guild settings are normalized to `modules.pet = false` when settings are loaded.
- `/help` and `COMMAND-GUIDE.md` now mark Pet as Coming Soon.
- Existing Pet model/module source is retained so the feature can be developed later.
