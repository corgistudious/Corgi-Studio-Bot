# Corgi-Bot V4.9 — Groq AI Free

- AI provider changed from OpenAI to Groq.
- `/ai` and `?ai` remain free and do not require Premium.
- Uses `GROQ_API_KEY` and `GROQ_MODEL`.
- Default model: `openai/gpt-oss-120b`.
- No extra npm package is required; Node.js 20 built-in `fetch` is used.
- Added timeout handling and clearer errors for invalid key, rate limit, and empty responses.
- Developer Control now reports Groq AI configuration status.
- Blacklist and Maintenance enforcement remain unchanged and continue to apply to AI.
