# Corgi-Bot V4.17.0 — Server Stats & Reaction Role Builder

## Server Stats
- Refresh/check interval remains 3 seconds.
- Discord channel rename is sent only when the displayed value or language actually changed.
- Free, always-available stats: Members, Humans, Bots, Roles.
- Premium can toggle advanced stats individually: Online, Boosts, Boost Level, Emojis, Stickers, Categories, Text Channels, Voice Channels, Stage Channels, Forums, Announcements, Threads, Events.
- `/setup -> Server Stats` adds Premium stat controls plus Create/Repair Board.
- Stats category and stat channel labels follow the guild EN/VI language setting.
- Premium-only stat channels are removed when disabled or when Premium is no longer active; the four Free stats remain.
- `Online` is safely optional. Set `ENABLE_PRESENCE_STATS=true` and enable Presence Intent in Discord Developer Portal for accurate online counts.

## Reaction Role Builder
- Reaction Role panel now supports up to 20 Emoji -> Role mappings.
- Add flow: choose a Role, then enter Unicode/custom emoji.
- Remove mappings from the Builder.
- Choose a target text/announcement channel inside the Builder.
- Preview includes the configured Emoji -> Role list.
- Publish automatically attaches reactions and creates the ReactionRole bindings.
- Republishing updates the existing panel when possible and rebuilds bindings.
- Role hierarchy checks prevent selecting managed/unassignable roles.
