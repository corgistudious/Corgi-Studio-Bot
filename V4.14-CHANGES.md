# Corgi-Bot V4.14.0 — Amber Event Control Center

## Event Control Center
- Added `/setup` → **Events**.
- Added persistent **Giveaway Builder** and **Contest Builder** drafts.
- Admins configure events with buttons, channel/role selectors and modals instead of long slash-command option lists.
- Added Preview, Publish and Reset Draft flows.
- Added Active Events overview.
- Direct image/banner capture: press Upload Image/Banner and send one image in the current channel within 60 seconds.

## Giveaway
- `/giveaway panel` opens the Builder.
- `/giveaway end`, `/giveaway pause`, `/giveaway resume`, `/giveaway reroll` remain as quick commands.
- Prefix `?giveaway` points admins to `/setup` → Events.
- Premium custom Join emoji is still enforced.

## Contest
- `/contest panel` opens the Builder.
- Member `/contest submit` remains unchanged.
- Quick moderation/lifecycle commands remain available: approve, reject, approve_all, close_submissions, open_vote, end_vote, results, publish and cancel.
- Prefix `?contest` points admins to `/setup` → Events.

## Amber Theme
- Amber accent applied to Setup Control Center, Giveaway, Contest, submissions, rankings/results and new Event Builder screens.
- English remains the default language; Vietnamese remains synchronized through `/setup` → Language.

## Data
- New `EventDraft` MongoDB model stores persistent Giveaway/Contest drafts.
- No destructive migration is required.
