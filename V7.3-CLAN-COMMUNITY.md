# Corgi-Bot V7.3.0 — Clan Community Hub

Clan is a community/group-management system, not a separate gameplay economy.

## Clan Rank
D (0) → C (10K) → B (30K) → A (75K) → S (150K) → SS (300K) → SSS (600K Clan Points).
Each rank has a dedicated Clan Hub embed color.

## Contribution
1 CXu contributed = 1 Clan Point. CXu is deducted from the member's global wallet. The same amount is added to the Clan total and the member's lifetime Clan contribution. Rank-up is automatic.

## Hub
Members can register/find/apply, contribute, view members, review applications, manage the group, leave, or disband through direct-action buttons according to permission. Commands remain available in parallel.

## Retired Clan gameplay
Clan Shop, Treasury, Missions, Events, Buy, Deposit, Withdraw and public Clan Audit commands are retired. Legacy models are retained only to avoid destructive schema/data changes and to clean associated records if a Clan is permanently disbanded.

## Safe migration
Run `npm run migrate:clan-community` once before deployment. Existing Clan Points are initialized from the greatest preserved value among existing `clanPoints`, legacy Clan XP, or summed member contribution. Existing members are preserved.
