# Creature Hunt V4 — Full Game UI + Gameplay

V4 upgrades Creature Hunt from information embeds into feature-specific game screens while keeping Game Hub buttons and slash/prefix commands on one backend.

## Game screens
- Adventure Hub
- Hunt Zone world map
- Wild Encounter with real Pet artwork + Element asset
- Capture Result with captured Pet artwork
- Visual Collection (4 real Pet cards/page)
- Pet Detail character screen
- Training preview/confirm screen
- Skill upgrade preview/confirm screen
- Companion character screen
- Team Formation with up to 3 real Pet artwork cards
- Element Guide showing all 8 Element assets
- Dex Milestone screen
- PvP Arena lobby and Victory/Defeat result screens

## Gameplay
- 4 Hunt Zones with unlock progression and ecosystem pools
- 8 Elements and matchup damage
- 5 Capture Orbs
- Duplicate Pet -> Pet Essence
- Level 1-100 and Skill 1-10
- Favorite / Lock / Companion
- 3-Pet team
- SPD turn order + HP/ATK/DEF + Element combat
- PvP rating, streak, winner/loser Essence
- Dex milestone rewards

## Compatibility
Migration is additive and preserves existing Creature profiles, owned Pets, teams and Orbs.
V4 is designed to merge over the currently deployed Creature V2 source; it includes the V3 gameplay service/schema/migration plus V4 UI/commands.
