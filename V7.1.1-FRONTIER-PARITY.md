# Corgi-Bot V7.1.1 — Frontier Command ↔ Direct Action Parity

- Frontier gameplay actions are exported from one module and reused by buttons, slash commands and prefix commands.
- Added direct commands: /explore, /gather, /camp, /travel, /craft, /base, /creature, /expedition, /research, /world, /codex.
- Frontier fishing uses /frontier-fish (prefix ?frontierfish / ?ffish) to preserve the existing full /fish and /fishing system.
- Removed retired Game Hub, monthly tournaments, seasonal events and weekly-ranking runtime/model files.
- Existing MongoDB collections are not dropped automatically.
