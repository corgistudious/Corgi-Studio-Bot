# Corgi-Bot V9.1 Audit Patch

Production-safe patch based on V9.0 source from LuxVPS.

## Fixed / changed
- Frontier removed from active help, mission copy and interaction routing. Historical DB/model files are retained only to avoid destructive data removal.
- Global Missions now state the actual tracked activity and exact progress/reward; no Frontier reference.
- Market restored/upgraded into fictional Market Hub with CRYPTO, STOCK and SECURITIES categories, 12 fictional seeded assets, controlled 15-minute market ticks, portfolio buy/sell, and daily server bulletin independent of ownership.
- Market daily bulletin + strong-move alerts clearly state virtual/game-only status.
- Transfer anti-alt guard: Discord account age, Corgi progression/profile age, level/messages gate, cooldown, daily send/receive caps, unique-recipient cap, received-CXu forwarding lock, and TransferLedger audit trail. No IP collection required.
- Roulette slash command corrected to /roulette (legacy prefix aliases retained).
- Sic Bo/Roulette interactive button/select/modal routing restored.
- Poker/Liêng interactive session buttons restored; fold/check/showdown/one raise are handled.
- Lottery settlement service is now started on ClientReady (previously defined but not started).
- Spin custom-emoji button-label rendering fixed.
- Clan Pet War INVALID_CLANS internal error replaced with a user-facing explanation.
- 12-locale i18n audit passes.

## Data safety
No reset/delete migration for CXu, Creature/Pet, Clan, Fishing, Social Profile, Market Portfolio, or player progression.

## Deploy
1. Back up current /opt/corgi-studio and .env.
2. Replace source while preserving production .env.
3. npm ci
4. npm run validate
5. npm run migrate:v91
6. npm run deploy:commands  (required because /roullette -> /roulette)
7. pm2 restart corgi-studio-bot --update-env
8. pm2 save
