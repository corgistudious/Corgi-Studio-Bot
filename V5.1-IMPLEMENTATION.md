# Corgi-Bot V5.1 — Global Expansion, Market & Seasonal Events

Implemented in this build:
- 12-language server locale schema and selector: EN, VI, pt-BR, pt-PT, ES, FR, DE, JA, KO, ID, zh-TW, zh-CN.
- Corgi Market virtual-market game using Cstar only, with six fictional instruments, buy/sell, portfolio, P/L, Direct Action buttons and `/market` + `?market`.
- Market announcement channel setting, configurable model threshold/direction/cooldown, and background volatility notifier.
- Seasonal Event engine: Lunar New Year, Christmas, Mid-Autumn, Halloween, Easter, New Year. Valentine is intentionally excluded.
- Event materials drop as bonus rewards from eligible Game Hub actions; Fishing successful catches also roll event drops.
- Lunar New Year may directly drop red envelopes with Cstar.
- Event inventory, recipes, 1 crafted item -> 1 Gift Box, random Cstar Gift Box rewards.
- `/seasonal` + `?seasonal` Direct Action event panel.
- `/dev` Seasonal Event Control with enable/disable, start/end dates, Cstar range and drop multiplier.
- Separate server channel slots for Market announcements and Seasonal announcements.
- Additive V5.1 migration seeds virtual market and holiday templates without resetting player progression.

Localization release gate:
`npm run audit:i18n` intentionally fails while any legacy EN/VI-only `pick()` UI remains. This source still contains legacy V5 surfaces and therefore must NOT be described as 100% 12-language localized until the gate passes.
