# Corgi Studio V10.2 Complete Upgrade

Built on the validated V10.1 production source. No destructive player migration.

## Added in V10.2
- Global Contribution wallet (💎) and Gift Stars (⭐).
- Gift catalog: Rose, Gift Box, Diamond, Crown.
- `/gifts view|buy|send` with VI/EN labels.
- Profile details show Contribution + Gift Stars.
- Website API: `GET /v1/gifts`, `POST /v1/gifts/buy`, `POST /v1/gifts/send`.
- `/dev` Contribution & Gifts page + safe add/subtract control.
- `/baucua`: shared 30-second Bầu Cua betting rounds using virtual CXu.
- `/lon-nho`: shared 30-second Big/Small betting rounds using virtual CXu.
- Game Hub advertises the two new games.
