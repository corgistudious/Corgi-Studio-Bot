# Corgi-Bot V6.1 Clan + Web Upgrade

Implemented in this package:
- Old `/guild` runtime command/UI removed; `/clan` is the new entry point.
- Clan schemas: clan, members, ranks/permissions, contribution, trust, custom currency/treasury, applications, missions/progress, events, shop items, orders, audit trail.
- Default hierarchy: Hội Trưởng > Phó Hội > Quân Sư > Tinh Anh > Thành Viên.
- Legacy Guild economy migration script (`npm run migrate:clan`) preserves legacy collections and migrates member wallets.
- Mission tracker and scheduler now target Clan Guild systems.
- Verification supports only BLUE Verified and PURPLE Partner; old red/yellow badge assets removed.
- Semantic log colors for approval/decline and moderation events.
- Level card changed to 16:9 and can consume a member-uploaded Clan background asset.
- `/help` verification/Clan content updated and non-EN/VI locales pass through the configured 12-language localization layer.
- Web API exposes manageable Discord servers, shared server configuration, Discord channel/role context, and Clan read/create/update.
- Website adds authenticated `/dashboard` with shared module toggles and Clan setup.
- Clan logo/banner use file upload through the existing Supabase asset uploader; no image URL input is exposed.

Safety:
- Run `npm run validate` before restart.
- Run `npm run migrate:clan` before enabling Clan features in production.
- Legacy Guild collections are intentionally preserved by migration for rollback/data safety.
